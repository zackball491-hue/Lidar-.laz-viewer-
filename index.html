Nova Scotia Raster Layers▼
When enabled, mesh colours are sampled from the native DTM grid per pixel instead of being stretched from mesh vertices. This keeps small relief and ramp transitions sharper; the underlying mesh geometry is still controlled by Terrain mesh detail. Colour detail is limited by the native DTM grid, whose cells aggregate ground returns.
When enabled, the connected raster terrain uses the same colour calculation as the LiDAR points: the current Display Mode (Elevation, Local Relief, Slope or Hillshade), selected ramp, elevation range, relief amplitude, contrast, gamma, hillshade, intensity, brightness and saturation. Aerial imagery and provincial hillshade are prevented from tinting either the terrain surface or the optional point overlay. This makes the surface colours correspond to the point-colour rules instead of merely blending the ramp underneath a raster. The terrain mesh is interpolated from the DTM, so tiny differences can remain where an individual return's measured height differs from the interpolated mesh height. In Year mode, a combined mesh cannot show separate colours for overlapping survey years; its surface uses the first visible year's colour.
Advanced mode is off. The standard slider range remains capped at up to 16 million vertices. Turn this on to unlock a 32-million-vertex ceiling for powerful desktop GPUs. Enabling it does not rebuild the mesh immediately; move and release the detail slider to apply the higher target.
Default keeps the adaptive mesh density. Standard mode targets up to sixteen mesh vertices per native DTM sample (about 4× the mesh density along each axis), subject to a 16-million-vertex ceiling. Advanced mode raises this to up to 32 vertices per native DTM sample (about 5.7× per axis), with a 32-million-vertex ceiling. At a fully covered 32M-vertex mesh, vertex and index buffers can require roughly 2.7 GiB combined CPU and GPU memory, before temporary rebuild overhead; sparse coverage can reduce index memory, but actual use varies by terrain extent, browser and GPU. Use Advanced only on systems with substantial free memory. Interpolation smooths the surface but cannot create elevation measurements finer than the source DTM. The mesh rebuilds when you release the slider. Imported KMZ GroundOverlay images use the same terrain vertex buffer and matching triangle layout, with a small surface clearance to prevent depth-fighting. This setting affects the textured terrain mesh, not the underlying LAZ point display.
Raster imagery and hillshade now respond to the same Contrast, Gamma, Intensity, Brightness, Saturation and Hillshade controls as the LiDAR display; no separate raster brightness boost is applied.
When either raster is on, the viewer builds a connected triangular terrain mesh from the filtered ground elevations and drapes the full raster over it. The mesh follows the union of loaded LAZ tile footprints. Tile-edge cells use a small seam tolerance so grid alignment does not leave artificial cracks; genuine gaps between tiles remain unmeshed. Points are hidden by default to avoid a speckled look, but can be shown above the surface.
Layers are off by default. Turn one on after loading LAZ tiles; map images are requested only for the loaded terrain extent.
Imagery and hillshade are requested from official Nova Scotia map services for the loaded LAZ area and rendered as textures on the same 3D ground mesh. The mesh is adaptively sampled over the union of loaded LAZ tile footprints, with tile-edge seam handling to avoid artificial cracks. Aerial imagery is assembled from native 256 px cached map tiles into a high-resolution texture; hillshade uses the official map export. Internet access is required.

Local Relief colors each point by its height difference to the smoothed neighbourhood (window below), helping show subtle changes in ground shape.

Elevation Range▶
Narrowing the range amplifies small elevation differences — e.g. set a 2–4 m band over a mound to see its internal structure.
Local Relief (micro-topo)▶
Smaller window emphasizes small terrain variations; larger window brings out broad undulations. Smaller amplitude = more contrast.
Tone▶
Shading & Eye-Dome▶
Sun intensity brightens or reduces direct illumination. Shadow contrast controls how strongly slopes turn from lit to shaded. Sun colour tints the direct light; ambient light stays neutral and fills shadows. Multi-light blend moves between the chosen sun direction and a softer four-directional hillshade. The checkbox disables the four-light blend entirely.
Eye-Dome Lighting darkens depth discontinuities in screen space — the technique used by Potree — making terrain edges and small surface changes read more clearly. Turn it up for stronger terrain creases.
Point Rendering▶
World-scaled splats grow points with zoom so the ground reads as a continuous surface instead of sparse dots; the minimum size keeps the overview dense.
Background & Sky▶
Contours▶

Vertical Exaggeration▶
Stretches the vertical axis only — colors and shading follow the exaggeration so slope shading strengthens accordingly.

This is the HTML Edition of NS LiDAR Micro-Topography Viewer — it has no embedded points.

Click ⬆ Load LAZ / KML (or drag & drop) your .laz tiles from the Nova Scotia Elevation Explorer. Ground points are classified automatically, tiles join at their true UTM coordinates. Years start at their recorded elevations; use LiDAR Years → Vertical shift / Auto-fit years to correct systematic mismatches.

No GPS paths or markers are built in — this edition ships with zero embedded features. Draw your own with ＋ Path / ＋ Area / ＋ Marker in the 📍 Features panel, or drop a .kml / .kmz / .gpx to import placemarks, tracks and waypoints. Markers appear as labelled chips pinned to the terrain and export back out as .kml / .kmz / .gpx.

New — GPS path editor: open the 📍 Features panel and use ＋ Path / ＋ Area / ＋ Marker to draw new features directly on the terrain (click to add points, double-click or ✓ Done to finish), or ✎ to reshape any existing path: drag vertex handles, click near the line to insert a vertex, double-click a handle to delete it. Export everything back to .kml / .kmz (Google Earth) or .gpx (GPS units); style each feature with its 🎨 button, and edits persist in this browser.

Everything runs locally in your browser — no upload, no server.
